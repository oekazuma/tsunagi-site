tsunagi

家庭で撮りためた動画と写真を時系列で 1 本に繋ぎ、日本語字幕とサムネイルを付けて YouTube に非公開でアップロードする、個人用のツールです。

できること

  • iPhone や Insta360 の動画・写真を撮影日時順に 1 本の動画にまとめる
  • 無音の区間を落とし、字幕を YouTube の字幕トラックとして付ける
  • YouTube に非公開でアップロードし、再生リストに入れる

処理はすべて手元の Mac で行い、外部のサーバーは使いません。

YouTube アカウントへのアクセス

このツールは、利用者本人の YouTube アカウントに動画・字幕・サムネイルをアップロードし、再生リストへ入れるためだけに Google の API を使います。詳しくはプライバシーポリシーをご覧ください。
