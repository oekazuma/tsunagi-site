tsunagi プライバシーポリシー

最終更新日: 2026 年 9 月 17 日

tsunagi(以下「本ツール」)は、利用者が自分の Mac で動かす個人用のソフトウェアです。本ツールが Google アカウントの情報をどのように扱うかを説明します。

取得する情報と利用目的

本ツールは、利用者が Google のログイン画面で許可した YouTube アカウントに対して、次の操作を行うためだけに YouTube Data API を利用します。

  • 動画のアップロード(公開設定は非公開)
  • 字幕トラックとサムネイルの登録
  • 再生リストの作成と、再生リストへの動画の追加

本ツールは、動画・字幕・サムネイル以外の YouTube アカウントの情報(視聴履歴、登録チャンネル、連絡先など)を読み取りません。

情報の保存と共有

  • Google から受け取る認証トークンは、利用者の Mac の中にだけ保存します。
  • 動画やその文字起こしは、利用者の Mac の中で処理します。Google 以外の第三者に送信しません。
  • 本ツールの作者や第三者が、利用者のアカウントの情報を収集・閲覧することはありません。

アクセスの取り消し

Google アカウントの「アカウントにアクセスできるサードパーティ製のアプリとサービス」から、いつでも本ツールのアクセスを取り消せます。Mac に保存した認証トークンは、ファイルを削除すれば消えます。

Google API サービスの利用

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、限定的利用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。
